# STORYVAULT

Official digital literary sanctuary for author **Mretyun Jai B**.

## 🌟 Key Features
- **Anti-Screenshot In-Browser Canvas Reader**: DRM watermarking, screen-capture protection, dark/sepia/white theme modes.
- **Interactive Trilogy**: Branching story paths for *Can Love Survive?* (*Not Like This* vs *Only If It Waits*).
- **Direct UPI Verification**: Zero-fee instant book unlocks.
- **Midnight Rain Soundscape**: Pure Web Audio ambient background sound.
